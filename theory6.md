# Лабораторная 6 — теория для защиты

Комбо-ланчи, проверка состава при отправке, модальные уведомления,
`transform`, `position: fixed`.

## Блок комбо

- Grid на 3 колонки (`.combo-grid`), каждый вариант — flex-строка
  (`.combo`), каждое блюдо — flex-колонка: иконка + подпись
  (`.combo-item`: `flex-direction: column`, подпись под картинкой).
- Подпись про десерты мельче на 2px (16 → 14).
- Hover иконок: `transform: translateY(-5px) scale(1.1)` — сдвиг
  вверх + увеличение. `transition: transform 0.3s` — плавность.
  `transform` не трогает поток документа (соседи не дёргаются).

## Проверка состава (`js/combo.js`)

- 5 валидных комбо: суп+главное+салат+напиток, суп+главное+напиток,
  суп+салат+напиток, главное+салат+напиток, главное+напиток.
  Десерт — к любому.
- `comboError()` возвращает текст ошибки или `null`. Порядок важен:
  сначала «пусто», потом «только напиток/десерт», потом «салат без
  основы», «суп без пары», и только потом «нет напитка» — иначе
  салат без супа неверно попросит напиток.
- `submit`-слушатель на форме: если ошибка — `preventDefault()`
  (отмена отправки) + показать уведомление. Нет ошибки — форма
  уходит на httpbin как обычно.

## Уведомление

- Создаётся через `createElement` при каждой ошибке, `remove()`
  по кнопке «Окей» удаляет из DOM.
- `.notice-overlay`: `position: fixed; top: 0; left: 0; width: 100%;
  height: 100%` — поверх всего, не скроллится; flex центрирует
  окно по вертикали и горизонтали. `z-index: 100` — выше контента.
- `fixed` позиционируется от вьюпорта (в отличие от `absolute` —
  от ближайшего позиционированного предка).

## События

- `addEventListener('submit', ...)` на форме вместо клика по кнопке:
  ловит и Enter в полях тоже. `event.preventDefault()` — остановить
  стандартное действие (отправку).

## Что могут спросить

1. Перечислите валидные комбо. — 5 штук + десерт к любому.
2. Почему порядок проверок важен? — показать на салате без супа.
3. Что делает preventDefault? — отменяет отправку формы.
4. Чем fixed отличается от absolute? — fixed от вьюпорта, не скроллится.
5. Как центрировали модалку? — fixed-оверлей + flex center.
6. Зачем z-index? — поднять поверх остального.
7. Что делает transform? — визуальное искажение без сдвига потока.
8. Как уведомление удаляется? — `remove()` по клику «Окей».
